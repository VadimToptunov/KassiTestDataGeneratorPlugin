# Kassi Test Data — Roadmap

Полный план продукта: что уже выпущено и что планируется. Один плагин, растущий по версиям
(рост — **только данными**: валидные синтетические поля, MRZ, штрих-код данные), плюс платный
тариф и интеграции с экосистемой Kassi. Основано на исходных `mvp-spec` и `roadmap`.

**Цель покрытия (весь продукт):** вся Европа + Кипр + Австралия.

## Сквозные правила (действуют в КАЖДОЙ версии)

- **По одной за раз.** Версия выпущена и залистена до начала следующей.
- **Тест валидности на каждый генератор.** Валидный вывод проходит настоящий алгоритм, невалидный — падает. Это «ров» и честный листинг, а не маркетинг «умной точности».
- **Связная персона — сквозной инвариант.** Всё (ID, MRZ, tax ID, штрих-код) согласовано с одной персоной: та же DOB, пол, гражданство, страна.
- **Синтетика + безопасность везде.** Карты — только Luhn-валидные в тестовых/зарезервированных BIN; ID структурно валидные, но синтетические; ноль реального PII; всё офлайн и алгоритмично.
- **НАВСЕГДА вне области:** библиотека изображений/образцов документов — даже официально опубликованных. Мы генерируем данные (поля, MRZ, PDF417), не картинки образцов. Эта граница не двигается.

## v1.0 — ядро (Free) — ✅ Выпущена

Action «Insert Test Data» с поисковым попапом, вставка в позицию каретки, опциональный seed.
6 генераторов как per-country абстракции:

1. **Банковский идентификатор** — IBAN (ISO 13616 + mod-97), sort code + account (GB), BSB + account (AU). Valid + invalid.
2. **Карта (PAN)** — Luhn, тестовые BIN, + CVV + expiry. Valid + invalid.
3. **BIC/SWIFT** — ISO 9362, международно.
4. **Национальный / персональный ID** — NL BSN, DE Personalausweis, AU TFN (чек-сумма); GB NINo, CY (формат).
5. **Бизнес / tax идентификатор** — VAT (CY/DE/NL/GB), ABN (AU).
6. **Связная персона** — имя, DOB, адрес, банковский + tax идентификатор одной страны. Seed для воспроизводимости.

**Фактическое покрытие v1.0 (решение по срокам):**
- **IBAN / BIC / карта / персона → вся Европа + AU** (алгоритмы обобщаются).
- **Нац. ID + VAT с настоящими чек-суммами → CY/DE/NL/GB/AU**, расширение по странам далее.
- UI показывает комбинацию «страна × генератор» только если её подтверждает реальный тест.

**Ship-gate (пройден):** от шаблона до одного залистенного free-плагина, каждый генератор покрыт тестом валидности. 31 тест зелёный.

## v1.1 — MRZ (Free) — 🔜 Следующая

Флагманский дифференциатор для KYC-парсинга. Machine-readable zone по ICAO 9303: **TD1** (ID-карты, 3×30), **TD2**, **TD3** (паспорт, 2×44) с корректными контрольными цифрами (номер документа, DOB, expiry, композит). MRZ кодирует ту же персону, что и v1.

- Valid + варианты с намеренно сломанной контрольной цифрой (по каждому полю — для точечного тестирования error-path).
- Только по набору стран v1.
- *(Заготовка уже есть: `Checksums.icao731CheckDigit` реализует ICAO 7-3-1 и покрыт тестом.)*

**Ship-gate:** любая строка TD1/TD2/TD3 проходит эталонный парсер контрольных цифр в тесте; сломанный вариант падает на нужном поле.

## v1.2 — расширение стран → вся Европа (Free, по спросу)

Каркас per-country + тест-харнесс проверены, breadth безопасен. Прогнать ВСЕ генераторы (bank / national / tax / BIC / MRZ) по остатку целевого покрытия с **настоящими чек-суммами по каждой стране**.

- **Полное европейское покрытие:** EU-27 + EEA (Норвегия, Исландия, Лихтенштейн) + UK + микро-государства. Финализировать Австралию (schemes уровня штатов).
- **Порядок — по спросу** из free-листинга (запросы/отзывы), не по догадкам.

**Ship-gate:** каждая новая страна выходит со своими тестами валидности, тот же стандарт, что в v1.

---

## v1.3 — больше document-data (Free)

Больше типов данных (не картинок):

- **PDF417 / AAMVA** — данные штрих-кода водительских прав США, синтетические, для тестов парсеров.
- Форматы номеров DL EU/AU, TIN/tax ID, дополнительные национальные схемы.

Всё с корректными чек-суммами, синтетическое, согласованное с персоной.

**Ship-gate:** данные штрих-кода декодируются эталонным AAMVA-парсером в тесте.

## v2.0 — платный тариф + доставка (точка монетизации) 💰

Здесь free→paid. Команды и профи платят за объём и пайплайн — без сервера, всё локально:

- **Массовая генерация в файл** (CSV/JSON): N связных персон для data-driven и нагрузочного тестирования.
- **CLI / headless-режим:** генераторы как фикстуры в CI.
- **Полное покрытие стран** (длинный хвост).
- **Полный набор document-data** (все типы MRZ, PDF417) в одном.
- **Шаблоны персон с ограничениями:** «50 персон, DE, 18–25 лет, у каждой валидный IBAN + один невалидный вариант».

**Монетизация:** нативно через JetBrains (15%, VAT обрабатывается, perpetual + продление обновлений).

**Ship-gate:** платёжный поток и лицензирование через Marketplace проходят end-to-end на тестовой покупке.

## Принцип секвенирования

Breadth (страны) — только после того, как depth (корректность + тест-харнесс) доказана в v1.
Монетизация — только после того, как free-ядро прошло полный релизный цикл и собрало сигнал спроса.
Каждая версия закончена и залистена до начала следующей. «Шарики» (глобальные образцы документов,
изображения) остаются вне области **навсегда** — не по мотиву, а по тому, чем такой актив становится,
будучи собранным.
